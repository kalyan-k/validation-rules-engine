# Changelog

All notable changes to the synchronized Validation Rules Engine package release are documented here. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0

Initial stable public release.

- Framework-neutral policy and rule engine in `@validation-rules-engine/core`.
- Angular forms adapter, directives, services, components, and display strategies in `@validation-rules-engine/angular`.
- React provider, hooks, controlled-field helpers, and accessible validation components in `@validation-rules-engine/react`.
- Angular and React comparison showcases, documentation, reports, and cross-browser automation.
- Single-origin production host for the portal, documentation, showcases, reports, and automation summary.
