About

Validation Rules Engine

An open-source TypeScript platform for reusable, policy-driven validation across frameworks — without locking business rules into UI components.

Our mission

Help teams define validation once as portable policies, then apply the same rules in Angular, React, Vanilla JS, and framework-neutral TypeScript applications with consistent results and clear ownership boundaries.

What we build

  • Core — framework-neutral policies, validators, groups, and model-state contracts.
  • Angular & React adapters — lifecycle-aware integrations that keep UI frameworks as consumers, not rule owners.
  • Live showcases & docs — runnable examples, state-management guides, and deployment evidence for Azure, GitHub Pages, and local hosting.

Principles

Policy first

Business rules live in reusable policies so forms, stores, and frameworks stay interchangeable.

Clear boundaries

Core stays framework-neutral; adapters and showcases consume published package contracts.

Evidence over claims

Tests, coverage, Playwright automation, and security scanning evidence ship with the hosted site so quality is inspectable.

Open source

Validation Rules Engine is released under the MIT License. Contributions, issues, and discussions are welcome on GitHub.
